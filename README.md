# Alokit MBR deck (Apr–Sep 2026)

Interactive monthly business review — open in any browser.

**Live site:** after GitHub Pages is enabled, use  
`https://<your-github-username>.github.io/alokit-mbr-deck/`

## Update the live deck

1. Rebuild locally: `python3 ~/Downloads/build_interactive_mbr.py`
2. Copy: `cp ~/Downloads/alokit-mbr-apr-sep-2026-presentation.html index.html`
3. Commit and push to `main`

GitHub Pages serves `index.html` from this repo on each push (usually within 1–2 minutes).
